# Troubleshooting

Science is hard, and getting computers to do what you want sometimes feels impossible.
If you need help, join the discussion at <https://help.c-moor.org>!
  For advice on how to write a good question (so you are likely to get useful answers), see [this StackOverflow post](https://stackoverflow.com/help/mcve).
